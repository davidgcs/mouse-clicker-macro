Mouse Macro Recorder

Record your mouse movements, clicks and scrolling, then replay them once or in a loop. A small, free app for Windows and Mac.

How it works

  1. Record. Click Record and wait for the 3, 2, 1 countdown, or press F1 to start straight away. Then move and click as usual.
  2. Stop. Click Stop or press F2. The macro is saved as a file in the MouseMacros folder in your user folder.
  3. Replay. Click Repeat to play it once, or set how many times to repeat it (empty means forever) and how long to wait between runs (5 seconds by default), then click Loop. Pause freezes a replay or a loop where it is, and Resume carries on from there.
  4. Keep your macros. Save as… saves the macro under a name and in a folder you choose, Import… opens one you saved earlier, and the folder icon next to its path shows the file in File Explorer or Finder.

The shortcuts can be changed in the app: F1 starts recording, F2 stops (it also stops a replay or a loop), F3 starts or resumes the loop and F4 pauses it.

First start on Windows

  1. Open the downloaded MouseMacroRecorder-Windows.exe. There is nothing to install, so you can keep it anywhere, for example on your desktop. If your browser warns that the file isn't commonly downloaded, choose to keep it.
  2. If Windows says “Windows protected your PC”, click More info and then Run anyway.
  3. The app takes a few seconds to start, because it unpacks itself first.

These warnings appear because the app isn't signed with a paid certificate. To record or replay in apps that run as administrator, run this app as administrator too.

First start on a Mac

  1. Unzip the download if your browser hasn't already, and drag Mouse Macro Recorder to your Applications folder. Then open it.
  2. If macOS says it can't verify the app, close the message. Then open System Settings → Privacy & Security, scroll down, click Open Anyway and confirm.
  3. Allow mouse access in System Settings → Privacy & Security: turn on Mouse Macro Recorder under Input Monitoring (to record and for the shortcuts) and Accessibility (to replay). If it isn't listed, add it with the + button. The app's red notice has a button that opens these settings. Then quit and reopen the app.

These steps are needed because the app isn't notarized by Apple. After you install a newer version, macOS may no longer recognise it: remove Mouse Macro Recorder from both lists with the − button, then open the app and allow it again.

On Mac laptops, F1 to F4 change the screen brightness, open Mission Control and so on unless you hold fn. You can also pick other shortcuts in the app.

Why doesn't it run in the browser?

Browsers don't let web pages watch or move your mouse outside their own tab, so that no page can spy on you or click things for you. Recording and replaying across your whole screen needs a desktop app, which is why this page offers it as a download.

Good to know

  • Replay uses screen positions, so use the same screen layout and resolution you recorded with.
  • Only the mouse is recorded, not the keyboard.
  • Only import macros you trust, because a macro can click anything on your screen.
  • If your antivirus blocks the app, you can run it from the source code instead. The README explains how.
